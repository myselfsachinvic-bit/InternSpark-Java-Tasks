# InternSpark Java Developer Internship

## Task 3: Console-Based Student Management System

### Objective

The objective of this task is to develop a simple console-based Student Management System using Java.

The application allows users to add, view, search, update, and delete student records through a menu-driven interface.

### Features

* Add a new student
* View all students
* Search student by ID
* Update student information
* Delete student
* Validate numeric input
* Prevent duplicate student IDs
* Exit the application

### Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming
* Console-based user interface

### Project Structure

```text
Task-3-Student-Management-System/
├── Student.java
└── StudentManagementSystem.java
```

### Source Code

The project contains two classes:

**Student.java**

The Student class stores student information including ID, name, age, and course. It also contains getters, setters, and a method for displaying student information.

**StudentManagementSystem.java**

This class contains the main application and implements the menu-driven operations for adding, viewing, searching, updating, and deleting students.

### How to Run

Compile both Java files:

```bash
javac Student.java StudentManagementSystem.java
```

Run the application:

```bash
java StudentManagementSystem
```
